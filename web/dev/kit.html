Lesson 4 · Memory

Page faults: memory that appears when you touch it

A program can ask for 64 MiB and receive it instantly, yet none of it exists until the first byte is written.

Evidence: 11 of 12 availableAbout 12 minutes

1 Question

Observed

General

When a program asks for memory with mmap, the kernel records a promise: a range of virtual addresses and what should back them. It does not find a single physical frame. The first access to each page traps into the kernel, which only then allocates a frame, fills it and installs the page-table entry.

  • a minor fault needs no I/O;
  • a major fault waits for a disk read.

8 Limits

Misconception

“64-bit means 2⁶⁴ bytes are addressable.”

Only 48 or 57 bits are translated; the rest must copy the top translated bit.

What this cannot establish

An unprivileged program cannot read the real page tables, so frame numbers here are hidden.
